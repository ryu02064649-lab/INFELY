# RELY ブランドフィルム（20秒・音付き）

Instagram リール・ストーリーズ用の縦型動画です。
映像素材・音楽素材・テンプレートは使っていません。
**映像も音も、すべてコードで作っています。**

| 項目 | 内容 |
|---|---|
| サイズ | 1080 × 1920（9:16） |
| 長さ | 20秒 |
| コマ数 | 30fps（600コマ） |
| 形式 | MP4（H.264／音声 AAC 48kHz ステレオ） |

## 動画を書き出す

```bash
npm run rely:film
```

→ `film/out/rely-film.mp4` ができます（書き出しは3分ほど）。あわせて次のファイルもできます。

- `score.wav`：音だけのファイル
- `poster.png`：カバー画像用の1枚
- `timeline.json`：場面の切り替わり時間

確認用の静止画だけを書き出す場合：

```bash
npm run rely:film -- --stills 3.4,11.1,18.2
```

### 別のパソコンで書き出すとき

- 初回だけ `npx playwright install chromium` が必要です
- 手元の Chrome を使う場合は、環境変数 `CHROMIUM_PATH` にパスを入れます

## 場面と時間

| 時間 | 場面 | 音 |
|---|---|---|
| 0.0 – 1.9 | 暗闇。ロゴの表面を一筋の光が滑る | 静かな和音が立ち上がり、高い音がひとつ |
| 1.9 – 4.8 | **RESEARCH**：深夜のデスク。ノートとパソコン、窓の外に街の灯り。「探す。」 | ピアノの音が2つ |
| 4.8 – 7.3 | 情報の断片（Restaurant・Hotel など）。「比較する。」 | 和音が少し翳る |
| 7.3 – 10.0 | 5つ → 3つ → 1つ。残った1つは細い線になり、その線が扉のように開く | 3つの音が降りてきて、1つに |
| 10.0 – 12.2 | **DINING**：キャンドルの灯るテーブルで、2人が乾杯する | グラスが触れ合う音 |
| 12.2 – 14.5 | **GIFT**：テーブル越しに、贈り物を手渡す | 小さな鐘のような音 |
| 14.5 – 17.0 | 「あなたが選ぶ。」／線／「その前を、RELYが。」 | ピアノの音が2つ |
| 17.0 – 20.0 | ロゴ、RELY、PRIVATE RESEARCH & CONCIERGE、「あなたの時間を、もっと自由に。」→ 黒 | 低い響きと、残る和音。黒と一緒に消える |

登場する人物は、すべてコードで作った架空の人物です（実在の人物・お店は出てきません）。
顔は映さず、手元や後ろ姿、ぼけた輪郭で見せています。

## 構成

| ファイル | 役割 |
|---|---|
| `film.js` | 映像のすべて（時間の設計、文字、ロゴ、場面のつなぎ） |
| `score.mjs` | 音のすべて（和音、ピアノ、グラスの音、響き）。`film.js` の時間表 `T` に合わせて鳴ります |
| `index.html` | プレビュー画面。書き出しのときにも使います |
| `render.mjs` | 書き出し（Chromium で1コマずつ描き、音と一緒に ffmpeg で MP4 にします） |
| `scenes/` | 3つの場面を Blender で作るコード（人物は `people.py`） |
| `assets/` | 作った場面の画像（書き出しで使います） |
| `fonts/` | サイトと同じ書体。サイトのビルドからコピーしたもの |

### 場面の画像を作り直すとき

```bash
python3 film/scenes/textures.py            # パソコン画面とノートの模様
python3 film/scenes/render_scenes.py all final   # 3場面（1枚5分ほど）→ film/assets/
```

`pip install bpy`（Blender）が必要です。

## プレビュー

```bash
python3 -m http.server 8765    # rely フォルダで
# → http://localhost:8765/film/index.html
```

- プレビューは映像だけです（音は書き出した MP4 で確認してください）
- 「動きを減らす」設定の端末では自動再生しません

# RELY ブランドフィルム（15秒）

Instagram リール・ストーリーズ用の縦型動画です。
映像素材やテンプレートは使っていません。すべてのコマ（フレーム）をコードで描いています。

| 項目 | 内容 |
|---|---|
| サイズ | 1080 × 1920（9:16） |
| 長さ | 15秒 |
| コマ数 | 30fps（450コマ） |
| 形式 | MP4（H.264・無音の音声トラック付き） |

## 動画を書き出す

```bash
npm run rely:film
```

→ `film/out/rely-film.mp4` ができます。あわせて次の2つもできます。

- `poster.png`：カバー画像用の1枚
- `timeline.json`：場面の切り替わり時間

1コマずつ正確に描いてから動画にするので、パソコンの速さに関係なく、コマ落ちはしません（書き出しは2分ほど）。

確認用の静止画だけを書き出す場合：

```bash
npm run rely:film -- --stills 1.1,3.4,10.5
```

### 別のパソコンで書き出すとき

- 初回だけ `npx playwright install chromium` が必要です
- 手元の Chrome を使う場合は、環境変数 `CHROMIUM_PATH` にパスを入れます

## プレビュー

`rely` フォルダでサーバーを起動し、ブラウザで開きます。

```bash
python3 -m http.server 8765
# → http://localhost:8765/film/index.html
```

- 下のバーで再生・停止と、好きな時間への移動ができます（スペースキーでも再生・停止）
- 「動きを減らす」設定の端末では自動再生しません。最後の場面を表示し、Play を押したときだけ再生します

## 場面と時間（BGM を合わせるとき用）

| 時間 | 場面 |
|---|---|
| 0.0 – 2.0 | 暗闇。ロゴの表面を、一筋の光が一度だけ滑る |
| 2.0 – 4.5 | 黒い大理石の空間へ、カメラがゆっくり前進。縦の光が横切り、「探す。」が光と一緒に現れる |
| 4.5 – 7.0 | 情報の断片（Restaurant・Hotel など）が、奥行きの中に一瞬ずつ現れる。「比較する。」 |
| 7.0 – 9.5 | 5つ → 3つ → 1つ。残った1つは細い線に置き換わる |
| 9.5 – 12.0 | 静寂。「あなたが選ぶ。」／線／「その前を、RELYが。」 |
| 12.0 – 14.0 | ロゴ。ゆっくり光が走り、RELY と PRIVATE RESEARCH & CONCIERGE |
| 14.0 – 15.0 | 「あなたの時間を、もっと自由に。」少し止まって、黒へ（最後に消えるのは RELY） |

同じ内容が `film/film.js` の `CUES` と、書き出した `timeline.json` にも入っています。

## 構成

| ファイル | 役割 |
|---|---|
| `film.js` | 映像のすべて（時間の設計、大理石の生成、光、文字、ロゴ） |
| `index.html` | プレビュー画面。書き出しのときにも使います |
| `render.mjs` | 書き出し（Chromium で1コマずつ描き、ffmpeg で MP4 にします） |
| `fonts/` | サイトと同じ書体（Bodoni Moda・Jost・しっぽり明朝）。サイトのビルドからコピーしたもの |
| `tools/extract-fonts.mjs` | `fonts/` を作り直すツール。画面の文字を変えたら `npm run build && npm run rely:film:fonts` |

ロゴは、サイトと同じ `public/images/emblem.webp` を使っています。
Web サイト本体（`src/`）には手を入れていません。

## 調整するとき

- **文字**：`film.js` の上のほう（`WORD_SEARCH` など）
- **時間**：各場面の関数（`sceneOpening`・`sceneRoom` …）の秒数
- **動きの速さの感じ**：`EASE`（どれもゆっくり始まり、ゆっくり止まるカーブ。等速の動きは使っていません）
